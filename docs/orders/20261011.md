# Task Order: Improve UI performance for large register selections

## Date: 2026-10-11

## Summary
Improve UI performance in NovaModbus Client and Slave when selecting large numbers of registers (e.g., 0–65535) to prevent slowdowns or UI freezes.

## Changes Made

### NovaModbus.Client
- **WatchEntry.cs** (new implementation):
  - Changed from `record` to `class` implementing `INotifyPropertyChanged`, `IEquatable<WatchEntry>`, `ISelectable`
  - Added `IsSelected` property for ViewModel-based selection state
  - **Added `SuppressSelectionNotification`** — prevents PropertyChanged during bulk selection
- **WatchViewModel.cs**:
  - Optimized `RemoveEntries` to rebuild collections in O(n) time instead of O(n²) by filtering once.
  - Optimized `AddRangeAsync` to merge new entries and reset collections once instead of per-item Adds.
  - Minor optimization in `ReadAllAsync` to iterate over `Results` directly.
  - **Added `BulkObservableCollection<T>`** (in `NovaModbus.Rtu.Collections`) — suppresses `CollectionChanged`/`PropertyChanged` during bulk operations, fires single `Reset` notification.
  - **Enhanced `SetAllSelected(bool)`** — sets `SuppressSelectionNotification=true` on each item before changing `IsSelected`, then restores it. This prevents 65k individual `PropertyChanged` events.
  - **`ISelectable` interface extended** with `SuppressSelectionNotification` property.
  - **Internal `_suppressItemSelectionNotification` flag** for collection-level awareness.
  - **Used `BulkObservableCollection` for `Entries` and `Results`** — `AddRange`, `RemoveRange`, `ReplaceAll` now single-notification.
  - **Added `ClearAllCommand`** — clears all entries/results in one operation (`ReplaceAll([])`).
  - **Added `SelectAllCommand` / `DeselectAllCommand`** — uses `BulkObservableCollection.SetAllSelected(bool)` for instant bulk selection (no UI freeze).
  - Removed old `IsSelectAllActive` flag and `GetEntriesToDelete()`.
- **MainWindow.xaml**:
  - Enabled UI virtualization with recycling mode for `WatchGrid` and `Results` grid.
  - Added **CheckBox column** bound to `IsSelected` (replaces DataGrid built-in selection).
  - Added **"Select All" / "Deselect All" buttons** bound to ViewModel commands.
  - Added **"Clear All" button** bound to `ClearAllCommand`.
- **MainWindow.xaml.cs** (simplified):
  - **Ctrl+A handler** — calls `SelectAllCommand` (instant, single notification).
  - **Delete handler** — uses `Entries.Where(x => x.IsSelected)` (ViewModel-based selection).
  - Removed old batched visual selection code and `IDisposable` implementation.

### NovaModbus.Slave
- **RegisterRow.cs / CoilRow.cs** (enhanced):
  - Added `ISelectable` implementation with `IsSelected` property for ViewModel-based selection.
  - **Added `SuppressSelectionNotification`** — prevents PropertyChanged during bulk selection.
- **MainViewModel.cs**:
  - Optimized `AddHolding` and `AddCoil` to insert new rows at the correct sorted position instead of full rebuild.
  - Optimized `AddHoldingRangeAsync` and `AddCoilRangeAsync` to rebuild only the affected grid (HoldingRows or CoilRows) from the source map after bulk operations, using `BulkObservableCollection`.
  - **Changed `HoldingRows` and `CoilRows` to `BulkObservableCollection<T>`** — supports `SetAllSelected`, `RemoveRange`, single-notification bulk ops.
  - **Added `SelectAllHoldingsCommand` / `DeselectAllHoldingsCommand` / `SelectAllCoilsCommand` / `DeselectAllCoilsCommand`** — instant bulk selection via `SetAllSelected(bool)`.
  - **Modified `RemoveHoldings` / `RemoveCoils`** — use `RemoveRange` with predicate instead of full `RefreshRows()`.
  - **Made `StatusText` setter public** for UI code-behind access.
- **MainWindow.xaml**:
  - Enabled UI virtualization with recycling mode for `HoldingGrid` and `CoilGrid`.
  - Added **CheckBox column** bound to `IsSelected` on both grids.
  - Added **"Select All" / "Deselect All" buttons** for both grids.
- **MainWindow.xaml.cs** (simplified):
  - **Ctrl+A handler** — calls ViewModel command (instant, single notification).
  - **Delete handler** — uses `Where(x => x.IsSelected)` instead of `SelectedItems`.
  - Removed old batched visual selection code and `IDisposable` implementation.

## Verification
- Build succeeded with 0 warnings.
- All tests passed (130/130).
- **Critical fix**: `SetAllSelected` now suppresses **both** collection notifications AND item-level `PropertyChanged` events via `ISelectable.SuppressSelectionNotification`.
- Manual verification confirmed that selecting/deselecting 0–65535 registers (65,536 items) completes **instantly with no UI freeze**.
- Delete/clear operations on full selection also complete without freezing.
